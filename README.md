# arshpreet singh — portfolio

My portfolio, built as a scroll-driven flight from Earth, past every planet, to the Sun. Each
stop along the way is one of my projects.

**Live:** https://arsh-space-portfolio.vercel.app

## Stack

- React + TypeScript on Vite
- GSAP ScrollTrigger for the scroll timeline, Lenis for smooth scrolling on desktop
- Three.js for the real-time layer: starfield, ship, landing pad, galaxy, comet, Jupiter's moons, Sun corona
- Pre-rendered footage for each planet, scrubbed by scroll as WebP frame sequences
- A small Vercel function (`api/chat.ts`) behind the "Ask about Arsh" guide

## How it works

The page is one long scroll split into scenes (`src/scenes/journey.ts`). Scroll position drives
everything:

- `SceneManager` maps scroll progress to the active scene and a local 0–1 progress within it
- `SpaceCameraController` turns that into camera movement and backdrop crossfades
- `PlateLayer` loads the current and upcoming backdrops and scrubs their frame sequences
- `SpaceCanvas` renders the Three.js layer on top
- a single GSAP timeline handles the text coming in and out of each scene

Phones get a separate layout (bottom-sheet cards, a menu) and a lighter render path: portrait
frame sequences, fewer particles, no ship, simpler transitions.

## Running it

```bash
npm install
npm run dev
```

To give the guide live answers, copy `.env.example` to `.env` and set `ANTHROPIC_API_KEY`.
Without a key it still answers from the site's own data.

## Assets

`public/plates` and `public/seq` are generated by `npm run assets` from source renders kept
outside the repo (see `scripts/build-assets.mjs`). Project screenshots in `public/projects` are
captured from the real sites with `scripts/capture.mjs`.
